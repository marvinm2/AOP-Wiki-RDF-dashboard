About this page

How one AOP's set of Key Events changed across the AOP-Wiki versions: which Key Events it had in each version, in which role, and when Key Events joined or left it. Pick an AOP by number or title; AOP links elsewhere on the dashboard (the completeness beeswarm, the Version Diff worklist) open it here.

One row per Key Event the AOP has had, one column per version from the AOP's first. A cell shows the Key Event's role in that version: molecular initiating event, key event or adverse outcome. ▸ marks a Key Event that joined the AOP in that version, × one that left it.
